# Lesson 1 flash cards — New cards only

Print this set once for Lesson 1. Print double-sided if your workflow supports it, or cut the table into rows and fold each row. Prompt yourself from Serbian to English and English to Serbian.

| Front | Back |
|---|---|
| Zdravo! · Здраво! | Hi! / Hello! |
| Dobar dan! · Добар дан! | Hello! / Good afternoon! |
| Ja sam ... · Ја сам ... | I am ... |
| Kako se zoveš? · Како се зовеш? | What is your name? (informal) |
| Kako se zovete? · Како се зовете? | What is your name? (polite/plural) |
| Drago mi je. · Драго ми је. | Nice to meet you. |
| Da. · Да. | Yes. |
| Ne. · Не. | No. |
| Učim srpski. · Учим српски. | I’m learning Serbian. |
| Malo. · Мало. | A little. |
| Hvala. · Хвала. | Thank you. |
| Vidimo se! · Видимо се! | See you! |
| ja · ја | I |
| ti · ти | you (informal singular) |

| si · си | are (informal singular) |
